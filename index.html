AI News Agent

A conversational AI agent built in n8n. A Gemini-powered agent with short-term memory takes a chat request, calls an RSS-read tool to pull fresh headlines on demand, and replies or sends the result straight to Gmail — all on request, no schedule needed.

Credentials for Gemini and Gmail live in n8n's encrypted credential store, never inline in the workflow — and the Gmail connection is scoped to send-only, not full mailbox access.

Daily News Digest

A scheduled n8n workflow that runs unattended every morning at 7 AM. It pulls and tags headlines from a list of RSS feeds, skips anything already sent so nothing repeats, compiles a digest, and emails it — no manual trigger required.

Runs on a fixed internal schedule rather than an exposed public webhook, and the "skip already sent" check doubles as a safeguard against reprocessing or replaying stale feed data.
